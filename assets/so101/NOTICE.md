# SO-101 model

`so101_new_calib.xml` and the meshes in `assets/` come from TheRobotStudio's SO-ARM100 repository
(https://github.com/TheRobotStudio/SO-ARM100, `Simulation/SO101`), generated with onshape-to-robot. Motor
parameters adapted there from the Open Duck Mini project. Licence: see the SO-ARM100 repository (Apache 2.0 at
the time of writing; check before redistribution). Unmodified; the pen, sheet, table, cameras and sensors are
added at load time by `buddy/sim/world.py`.
